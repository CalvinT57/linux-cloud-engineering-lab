# Linux Cloud Engineering Lab

## Overview

This repository documents my hands-on Linux learning journey with a focus on cloud engineering, system administration, networking, services, remote access, and troubleshooting.

Rather than only memorizing Linux commands, I am building a working lab environment and using it to practice tasks that relate directly to real cloud and infrastructure roles.

## Lab Environment

- Host System: macOS
- Virtualization: UTM
- Guest OS: Ubuntu Linux
- Remote Administration: SSH
- Web Server: Nginx
- Networking: Private virtual network
- Current Linux Hostname: `linux-lab`

## Skills Practiced

- Linux file and directory navigation
- Creating, copying, moving, and deleting files
- Working with Linux paths and directories
- Package management using `apt`
- Reviewing system logs
- Troubleshooting with `journalctl`
- Managing services with `systemctl`
- Installing and configuring OpenSSH
- Remote Linux administration from macOS
- Linux networking and IP identification
- Installing and validating Nginx
- Hosting a web page from a Linux server
